# Türkçe Kolay — التركية ببساطة

تطبيق Android أصلي لتعليم اللغة التركية للمبتدئين العرب تمامًا، بما فيهم من يجد صعوبة في الحفظ والقراءة. التعلّم بالصور أولًا، والصوت التركي، والتكرار المتباعد، وتمارين قصيرة بلا عقاب على الخطأ.

## ما في التطبيق

- **بلا تسجيل:** ابدأ فورًا؛ كل شيء يعمل دون إنترنت.
- **الحروف التركية الـ29** مع الصوت والصورة والمثال، وتركيز على Ç Ş Ğ I İ Ö Ü.
- **أول 30 كلمة، 16 عبارة أساسية، 20 فئة مصوّرة**، وجمل A1/A2، و4 محادثات.
- **بطاقات مرئية** بخمسة أنماط عرض (أ–هـ) تقلّ فيها المساعدة تدريجيًا.
- **عشرة أنواع تمارين:** اختيار الصورة، اختيار الكلمة، الاستماع، التعرّف على الحرف، توصيل الصور، توصيل المعاني، ترتيب الحروف، إكمال الجملة، لعبة الذاكرة، الاستماع والتكرار — إضافة إلى المحادثات.
- **«مراجعتي الذكية»:** تكرار متباعد حتمي (فوري، 1، 3، 7، 14، 30 يومًا) يعيد تعليم الكلمة المنسية ثم يسأل عنها بطريقة مختلفة.
- **الصوت:** تسجيلات ناطقين أصليين عند توفرها، ثم صوت الجهاز التركي، وزر مشطوب واضح عند عدم توفر أي منهما.
- **الوضع الهادئ، هدف يومي، سلسلة أيام، نقاط وإنجازات، تذكير يومي اختياري.**
- **معلّم ذكي اختياري** عبر خادم وسيط — لا مفاتيح داخل التطبيق.

## التقنيات

Kotlin · Jetpack Compose · Material 3 · Navigation Compose · Hilt (KSP) · Room · DataStore · WorkManager · Media3 · Android TTS · kotlinx.serialization · Retrofit/OkHttp · JUnit · MockK · Compose UI Test.
AGP 8.13 · Gradle 8.14.3 · Kotlin 2.2.20 · minSdk 26 · targetSdk 36.

## البناء

```bash
./gradlew testDebugUnitTest    # الاختبارات
./gradlew assembleDebug        # APK في app/build/outputs/apk/debug/
```

أو افتح المشروع في Android Studio. كل دفع إلى `main` يبني الـAPK تلقائيًا على GitHub Actions.
