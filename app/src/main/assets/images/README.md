# Illustrations

Version 0.1 uses system emoji as stable image references (`"image": "emoji:🍎"`), so every item
has a recognisable picture with no licensing risk. To ship custom illustrations, add files here,
e.g. `images/vocabulary/w_elma.webp`, and change the item's `image` to that path.
Record each file's source and licence in `images/ATTRIBUTION.md`. See docs/CONTENT_GUIDE.md.
