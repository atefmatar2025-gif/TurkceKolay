# تدقيق المشروع — Türkçe Kolay

تاريخ التدقيق: 6 نوفمبر 2026

## 1. حالة المستودع الحالية

فُحصت المستودعات المتاحة في حساب GitHub الخاص بالمالك (`life-os` و`ArabicShortwave` و`MyDay`). لم يوجد أي مستودع خاص بتطبيق Türkçe Kolay، ولا مشروع Android سابق له. بناءً على قرار المالك، يبدأ المشروع في **مستودع جديد مستقل** بدلًا من خلطه بمشاريع أخرى.

| البند | النتيجة |
|---|---|
| كود مصدري سابق | لا يوجد |
| مشروع Android سابق | لا يوجد |
| إعدادات Gradle واعتماديات | لا يوجد — أُنشئت من الصفر |
| أصول ووثائق | لا يوجد |
| أخطاء بناء قائمة | لا ينطبق |
| تكاملات API قائمة | لا يوجد |

لذلك لم يُحذف ولم يُستبدل أي ملف موجود.

## 2. بيئة التطوير المتاحة

- JDK 21 وGradle 8.14.3 متوفران في بيئة العمل.
- **لا يتوفر Android SDK ولا وصول للشبكة** في بيئة العمل، لذلك لا يمكن بناء الـAPK داخلها.
- الحل: يُبنى التطبيق ويُختبر على GitHub Actions (`.github/workflows/android-ci.yml`) حيث يتوفر Android SDK، ويُرفع الـAPK كملف ناتج (artifact).

## 3. البنية المقترحة (المنفّذة)

MVVM بطبقات منفصلة: عرض (Compose + ViewModel) ← مجال (منطق نقي قابل للاختبار) ← بيانات (Room + DataStore + الأصول). التفاصيل في `ARCHITECTURE.md`.

## 4. قرارات تقنية مهمة

| القرار | السبب |
|---|---|
| AGP 8.13.0 + Gradle 8.14.3 + Kotlin 2.2.20 + KSP 2.2.20-2.0.4 | مجموعة مستقرة متوافقة مع بعضها؛ KSP مطابق لإصدار Kotlin |
| compileSdk/targetSdk 36، minSdk 26 | يغطي الغالبية الساحقة من الأجهزة الحديثة ويسمح باستخدام java.time والأيقونات التكيّفية دون مكتبات إضافية |
| Hilt عبر KSP (بدون kapt) | بناء أسرع ومتوافق مع Kotlin 2 |
| المحتوى في JSON داخل assets ثم نسخه إلى Room | إضافة دروس دون تعديل الكود؛ التقدّم محفوظ في جداول منفصلة لا تُمس عند تحديث المحتوى |
| الصور: رموز تعبيرية (emoji) كمرجع ثابت مؤقت | كل عنصر له صورة واضحة فورًا دون مخاطر ترخيص؛ قابلة للاستبدال برسوم مخصصة دون تغيير الكود |
| الصوت: تسجيلات أصلية أولًا ثم TTS تركي | لا توجد تسجيلات أصلية مرخّصة بعد؛ البنية جاهزة لاستقبالها |
| المعلّم الذكي عبر خادم وسيط | لا مفاتيح سرية داخل التطبيق إطلاقًا |

## 6. المخاطر والحلول

| الخطر | الأثر | الحل |
|---|---|---|
| لم يُترجم الكود محليًا (لا SDK) | قد يظهر خطأ ترجمة في أول تشغيل لـCI | سير عمل CI يبني ويختبر عند كل دفع؛ أي خطأ يظهر في تقرير Actions ويُصلح مباشرة |
| جهاز بلا صوت تركي (TTS) | زر الصوت لا يعمل | الزر يظهر معطّلًا مع شرح، وزر «تثبيت الصوت التركي» في الإعدادات |
| غياب التسجيلات الأصلية | جودة نطق TTS أقل من الإنسان | بنية مجلدات جاهزة؛ إضافة ملف بنفس المعرّف تكفي |
| رموز emoji تختلف شكلًا بين الأجهزة | اتساق بصري أقل | خطة استبدال برسوم موحّدة (المرحلة 7) |
| أخطاء لغوية في المحتوى | تعلّم خاطئ | مراجعة من ناطق أصلي قبل الإصدار العام (TEST_PLAN) + اختبارات آلية لسلامة المراجع |
| تغيير مخطط Room لاحقًا | فقدان التقدّم | لا يوجد fallback مدمّر؛ كل تغيير يتطلب Migration |
| أخطاء المعلّم الذكي | معلومات غير دقيقة | تعليمات صارمة في الخادم + تنبيه في الواجهة + الميزة اختيارية |
