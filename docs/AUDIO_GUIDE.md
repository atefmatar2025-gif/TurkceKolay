# دليل الصوت

## أولوية التشغيل (`AudioRepository`)

1. تسجيل أصلي محمَّل: `filesDir/audio/<folder>/<id>.mp3`
2. تسجيل أصلي مخزَّن مؤقتًا: `cacheDir/audio/<folder>/<id>.mp3`
3. تسجيل أصلي مضمَّن في التطبيق: `assets/audio/<folder>/<id>.mp3`
4. صوت تركي من الجهاز (Android TTS، `tr-TR`)
5. غير متوفر ← زر الصوت يظهر مشطوبًا ويشرح السبب عند الضغط (لا يتظاهر بالعمل)

## المجلدات والأسماء

| النوع | المجلد | مثال |
|---|---|---|
| حرف | `alphabet/` | `l_ch.mp3` (Ç) |
| كلمة | `vocabulary/` | `w_elma.mp3` |
| عبارة | `greetings/` | `w_tesekkur.mp3` |
| جملة / مثال | `sentences/` | `s_bu_ne.mp3` ، `w_elma_ex.mp3` |
| محادثة | `conversations/` | `c_cafe_0.mp3` ، `c_cafe_0_r0.mp3` |

اسم الملف = المعرّف + `.mp3`، أو حدّد `"audio": "name.mp3"` في JSON.

## مواصفات التسجيل

- ناطق أصلي بلهجة إسطنبول القياسية، بيئة هادئة.
- MP3 أحادي، 44.1kHz، 96–128kbps، تطبيع الصوت إلى −16 LUFS تقريبًا.
- 300ms صمت قبل وبعد. نطق طبيعي غير مبالغ فيه.
- **لا تسجيل بطيء منفصل ضروري:** الوضع البطيء يستخدم تمديد الوقت في Media3 بسرعة 0.75× مع الحفاظ على طبقة الصوت. للحروف الصعبة يُفضّل تسجيل نسخة بطيئة طبيعية مستقبلًا.

## التسجيلات الحالية

202 تسجيل لناطقين أصليين من مشروع **Lingua Libre** (معظمها بصوت متحدث واحد للحفاظ على ثبات النطق)، تُجلب آليًا عبر GitHub Actions (`tools/assets/fetch_assets.py`) وتُطبَّع وتُحوَّل إلى MP3 أحادي، ثم تُثبَّت بـ `tools/assets/apply_assets.py --audio`. المصادر والرخص في `assets/credits.json` وشاشة «مصادر الصور والأصوات».

## السرعة والتكرار

- سرعة النطق قابلة للاختيار: بطيء جدًا / **بطيء (افتراضي)** / عادي.
- زر السلحفاة يشغّل بأبطأ سرعة ممكنة دون تشويه (TTS ‎0.45، التسجيل 0.7×).
- في بطاقات التعلّم تُكرَّر الكلمة 3 مرات افتراضيًا مع فاصل قصير (قابل للتغيير 1–3).

## TTS

- يُفحص توفر التركية (`READY` / `MISSING_DATA` / `NOT_SUPPORTED` / `ERROR`).
- يُختار أفضل صوت تركي غير متصل بالشبكة إن وجد.
- سرعات TTS: 0.5 / 0.65 / 0.9 حسب الإعداد.
- الإعدادات ← الصوت: زر «تثبيت الصوت التركي» يفتح شاشة النظام، و«إعادة فحص الصوت».
- أسماء الحروف تُنطق عبر `name` (مثل `çe`، `yumuşak ge`) لا عبر الحرف المفرد.

## الوضع الهادئ

لا تشغيل تلقائي، ولا تمارين تعتمد على السمع (الاستماع، التعرّف على الحرف بالصوت، الاستماع والتكرار).

## تقييم النطق

غير موجود عمدًا. تمرين «استمع وكرّر» يطلب التكرار بصوت مسموع دون ادعاء تقييم آلي.
